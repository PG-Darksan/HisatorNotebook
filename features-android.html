Android 版ならではの機能

持ち歩きと「ながら作業」 に効く機能です。

  • オートクリッカーユーザー補助 (アクセシビリティ) の仕組みで、 他のアプリの上に操作パネルを浮かべて自動でタップします。 1 か所を連打する「シングル」 と、 複数の場所を番号順にタップ・スワイプする「マルチ」 の 2 つのモード。 パネルから開始 / 停止、 ターゲットやスワイプの追加・削除、 間隔と止める条件 (無制限 / 時間 / 回数) の設定ができ、 保存した構成はアプリから呼び出せます。 初回はユーザー補助の設定で HisatorNotebook のサービスを有効にしてください。
  • バックグラウンド再生画面を消しても YouTube やローカル動画の音声が続きます (常駐通知付き)。
  • PiP (ピクチャーインピクチャー)小窓で再生しながらマップを編集。
  • 上下の画面分割と浮かぶメモボタンを長押しして「開き方」 から全画面 / 上に分割 / 下に分割を選べます。 メモは他のアプリの上に浮かべて使えます。
  • 通知とアラーム正確なアラームでリマインド。 端末が起動していなくても再設定されます。
  • 画面ロック / アプリ固定集中したい時間だけ端末をこのアプリに固定できます。
  • ホーム画面ショートカットよく使うページをホームに置けます。
  • 高リフレッシュレート90Hz・120Hz・144Hz などの端末で滑らかに描画します。 合わせるレートは「端末の最高」 か、 端末が対応するレートから選べます。

マインドマップ

ノード・接続・グループ・図形。 このアプリの中心機能。

  • ノードの作成と接続ドラッグでノードを近づけるとアンカーに吸着して線が繋がります。 8 方向のアンカー、 曲線の接続線、 矢印の大きさやラベルも設定できます。
  • ノードの中身メモ、 画像・動画・PDF などの添付、 リンク、 表 (テーブル)、 リッチテキストをノードに持たせられます。
  • 図形と装飾直線・矢印・長方形・楕円・波線・塗りつぶしなどの図形を自由配置でき、 テキストも添えられます。
  • フローチャート端子角丸端子・処理・判断 (ひし形)・入出力・準備 (六角形)・書類・データベース・手作業・工程・結合子の 10 種類。
  • グループ (付箋)複数ノードを名前付きグループにまとめ、 背景色・フォント・レイアウト (行数 / 整列) を指定できます。
  • 格納ノード選択した複数ノードを 1 つの代表ノードに畳んで、 必要な時だけ展開できます。
  • サブマップノードから別ページへリンクし、 ブラウザのように戻る / 進むで行き来できます。
  • 自動整列ツリー整列、 行 / 列の整列、 等間隔配置でマップを一瞬で整えます。
  • 検索と一括編集ノード検索 (マークダウン・文書・フリーノートの本文、 PDF のメモ、 ファイル名も対象)、 範囲選択、 選択したノードの一括編集 / 一括 AI 処理。
  • マップの統合複数ページのノード・接続・装飾をまとめて 1 つの新しいページに統合できます。

ページの種類

用途に合わせてページの種類を使い分けられます。

  • マインドマップ自由配置のノードキャンバス。 このアプリの中心です。
  • ギャラリー (本棚)動画・PDF・画像をタイルに並べる 2 次元グリッド。 行 / 列を掴んで増減でき、 見終わった動画の自動削除や連続再生にも対応。
  • フリーノート手書き / 図形 / テキストの自由ノート。 PDF を読み込んで 1 ページずつ並べ、 その上に書き込めます。
  • 文書ページ罫線付きの文章作成ページ。 文字数カウント付き。
  • マークダウンマークダウンを書きながらプレビュー。 AI 欄で本文の案を作ってもらい、 今の本文との違いを確かめてから適用できます。 Web への公開にも対応 (Max)。
  • 動画編集ページタイムライン式の簡易ビデオエディター (ffmpeg)。 テロップ・カット・書き出しに対応。
  • AI スタジオAI でスライドを生成し、 テーマやテンプレート (.pptx) を当てて仕上げられます。
  • フォルダとタブページはフォルダで整理でき、 お気に入り / 非表示 / 並べ替えにも対応。

AI

API キーの用意は不要。 前払いクレジットから使った分だけ差し引く方式。

  • API キー不要AI はアプリ側のキーで動きます。 アプリ内で $10 単位でチャージし、 使った分 (各社の実単価 + 20%) だけ差し引かれます。 応答のたびに残りが表示されます。
  • モデルの切り替えGemini / ChatGPT / Claude を応答ごとに選択可能。 単価が確認できた最新モデルだけを提示します。
  • マップの自動生成キーワードや用語からマップを丸ごと生成。 深さや子ノード数も指定できます。
  • ノード単位の AI説明を書かせる、 子ノードを増やす、 任意のプロンプトを流す、 ノードの中身について質問する。
  • ファイル / PDF から生成PDF や文書ファイルを読み込んで要約し、 マップ化します (Max)。
  • AI クイズ・フラッシュカードマップの内容から問題を作って復習できます。
  • AI 会話練習面接やロールプレイを AI と練習できます。 音声での会話にも対応。
  • モデル一覧の自動更新各社 API から最新モデルを取得。 設定画面を開くたびに最新へ更新されます。
  • 利用量とコスト表示入出力トークンと概算コスト (USD / JPY) を記録します。

動画・PDF・文書

見る / 書き込む / 編集するまでアプリの中で完結します。

  • YouTube 埋め込み動画をノードやギャラリーに貼り付け、 アプリ内で再生。 検索・プレイリスト取り込み・チャンネル取り込みにも対応。
  • 再生速度ローカル動画は最大 16 倍速まで。 速度は次に開く動画にも引き継がれます。
  • PDF ビューアページに紐付くメモ (PDF メモ)、 マーカー、 メモのフォルダ分け、 ノード化に対応。
  • 文書ビューア / エディタdocx / xlsx / pptx / csv / txt をアプリ内で開いて編集。 数式エンジン付きの表計算やプレゼンのプレゼンターモードも。
  • 画像編集トリミング (矩形 / フリーハンド)、 注釈、 テキスト入れ。
  • 読み上げ (TTS)PDF やテキストを音声で読み上げます。

Web とブラウザ

調べ物からノート化までを 1 か所で。

  • アプリ内 Google 検索検索しながらメモを取り、 その場でノード化。 ブックマーク、 タブ、 履歴に対応。
  • Web の自動操作 (Pro)タップ / ホールド / スワイプ / スクロール / 待機 / スクショを並べて自動実行。 「繰り返し」 ブロックで何度でも回せます。
  • スクショの管理実行ごとにフォルダ分け、 並べ替え、 回転、 枠をドラッグしての切り抜き、 見開きの左右分割、 まとめて PDF 化 (右から読む本は右綴じに)。
  • ブラウザ AIChatGPT / Gemini / Claude / Perplexity などをアプリ内で開き、 ノードの内容を送れます。
  • サイトのボタンYouTube / Google マップ / Earth / カレンダー / ドライブ / DeepL / Amazon / Kindle などをワンタップで。

情報を集める

ニュース・雑学・性能・本・試験の日程を、 アプリの中で調べられます。

  • トレンドIT・経済・株・仮想通貨・スポーツ・国内・国際・科学・エンタメのニュースをまとめて集め、 キーワードの順位と記事の一覧を表示。 記事の要約や用語の説明を AI に頼めます。
  • 雑学 (記事 / 動画)動物・歴史・科学・宇宙・食べ物・言葉などのジャンルを選ぶと、 雑学・豆知識の記事や動画を集めて一覧にします。 一覧を出したまま画面の中で開き、 前後の記事へ送れます。 記事・動画は配信元のページをそのまま表示し、 出典 (媒体名) を必ず添えます。
  • 性能比較CPU・スマホ・GPU・AI (LLM)・ブラウザの性能を、 PassMark・Geekbench・LMArena などの公開ベンチマークで一覧に。 最大 8 つを並べて比べ、 違いを AI に説明させることもできます。
  • 書籍検索Kindle ストアから本を探して、 表紙の並ぶ一覧で表示。 価格・著者・出版年月・Unlimited 対象作品などで絞り込めます。 Amazon の商品検索にも対応。
  • 資格試験の日程 (日本語版のみ)日本の資格試験の日程と申込先を一覧に。 分野や「受付中だけ」 で絞り込み、 締切の近い順に並べ、 試験日と申込の締切をカレンダーに登録できます。 受験料や過去問のページも開けます。

予定・共有・書き出し

作ったものを残す / 配る / 予定に落とし込む。

  • カレンダー予定の登録・共有 (グループ)、 ルーチンの複製、 タイムライン表示、 メンバー予定表。
  • リマインダーノードや予定から通知を予約。 Android は正確なアラーム、 Windows はトースト通知。
  • ガントチャートタスクの期間を横棒で俯瞰。
  • フラッシュカード暗記カードで復習。 csv / xlsx はそのままカードにでき、 PDF・画像・Word・PowerPoint からは AI で生成できます。
  • クラウド同期 (Max)グループコードでページや添付を共有。 3-way マージでローカル優先の安全な同期。
  • 共同編集と Web 公開 (Max)同期グループでファイルや予定表を共同編集でき、 ページのまとめての共有や、 マークダウンの Web 公開にも対応します。
  • LAN 共有同じネットワーク内の端末にページを配信。
  • エクスポートマップは単体で開ける HTML、 PDF、 画像に書き出せます。

集中とツール

  • 集中ロックToDo タスクを全部終えるまで、 または指定時間までロック。 スケジュールでの自動ロックにも対応。
  • ロック画面の中身メモ、 今日の予定、 ポモドーロ、 自然音 / ブラウンノイズ、 AI や検索への送信 (許可制)。
