Android 版ならではの機能

持ち歩きと「ながら作業」に効くモバイル専用の機能群です

  • オートクリッカー他のアプリの上に操作パネルを浮かべ、タップ・スワイプ・画像認識・OCR条件分岐を順番に自動実行（分かりやすい初回権限ガイド付き）
  • 無音カメラ ＆ OCR・QRリーダー図書館や教室でもシャッター音無しで写真・動画を撮影し、その場で OCR 文字起こしや QR 読み取りを実行
  • 上下 / 左右の画面分割 ＆ 120Hz/144Hz 描画2画面分割・フローティングメモと、高リフレッシュレート端末での滑らかな描画、集中ロックに対応

マインドマップ ＆ 6つのページ

タッチ操作でもPCと同等の6つのページ型と対話型チュートリアルを備えています

  • マインドマップ ＆ ギャラリー画像・動画・PDF・表・数式を格納できる無限マップと、資料をタイル状に並べる2次元ギャラリー
  • フリーノート ＆ 文書スタイラスや指で自由に書ける手書きキャンバスと、アウトライン目次付き文書ページ
  • マークダウン ＆ 動画編集・AIスタジオMermaid・LaTeX・差分比較対応のマークダウンと、タイムライン動画編集・AIスライド生成

AI (3大AI ＆ プリペイド方式)

API キー不要・Free プランから 3 大 AI を直ぐに使えます

  • API キー不要のプリペイド AI$10 チャージで使った分だけ消費・ChatGPT / Gemini / Claude を API キー不要で利用可能
  • マップ自動生成・暗記カード・AI会話練習テーマやPDFからのマップ・問題集・暗記カード生成と、音声での面接・語学ロールプレイに対応

動画・PDF・Office・リサーチ・クラウド同期

視聴・直接編集・試験対策・PCとの同期までスマホの中で完結

  • 広告無し YouTube ＆ PDF・Office 直接編集広告非表示のYouTube視聴、PDFへのペン直接焼き込み保存、Word / Excel / PowerPoint の直接編集
  • 検索・トレンド・雑学・性能比較・317試験対策2画面Google検索、9分野トレンド、雑学、CPU/GPU/スマホ/LLM比較、4大EC商品検索、AI試験対策
  • 自動保存・復元センター・クラウド同期即時自動保存と復元センターでデータを保護し、Windowsと競合無く自動マージ同期（Max）
