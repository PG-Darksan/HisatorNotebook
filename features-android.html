Android 版ならではの機能

持ち歩きと「ながら作業」に効くモバイル専用の機能群です。

  • オートクリッカー (マルチステップ・フロー形式)ユーザー補助 (アクセシビリティ) とオーバーレイの仕組みで、他のアプリの上に操作パネルを浮かべて自動タップ・スワイプ・長押し・待機・画像認識・OCR条件分岐を順番に実行する「フロー形式」に統一。ターゲットの追加・削除、間隔や停止条件 (無制限 / 時間 / 回数) の設定、フローの保存と呼び出しに対応しています。初回は分かりやすいステップ順の権限ガイド (Xiaomi / HyperOS 等の「制限された設定」解除案内つき) で迷わず設定できます。
  • 無音カメラ (写真・動画) ＆ OCR・QRリーダー図書館や教室、会議室でもシャッター音なしでホワイトボードや資料を撮影できる無音カメラを搭載。写真撮影と動画録画モードの切り替え (動画の音声録音 ON/OFF 対応) に加え、撮影した画像からその場で OCR 文字起こしや QR コード読み取りが可能です。
  • バックグラウンド再生 ＆ PiP (小窓再生)画面を消しても YouTube やローカル動画・音楽の音声が続くバックグラウンド再生 (メディア通知付き) と、小窓 (ピクチャーインピクチャー) で動画を浮かべながらマップやノートを編集できる PiP に対応。
  • 上下 / 左右の画面分割と浮かぶメモボタンを長押しして「開き方」から全画面 / 上下分割 / 左右分割を選択可能。分割ペインの上部ハンドルをドラッグして入れ替えや小窓化ができ、メモを他のアプリの上に浮かべて使うこともできます。
  • 正確なアラーム通知 ＆ ホーム画面ショートカット端末スリープ中でも正確な時刻に鳴るアラーム通知と、よく使うページを Android のホーム画面に直接配置できるショートカット機能を搭載。
  • 画面ロック / アプリ固定 ＆ 高リフレッシュレート (120Hz / 144Hz)集中したい時間だけ端末をこのアプリに固定するロック機能と、90Hz・120Hz・144Hz 対応端末で指に吸い付くように滑らかに描画する高リフレッシュレート制御に対応。

マインドマップ

ノード・接続・グループ・図形。タッチ操作でもPCと同等の表現力を備えています。

  • ノードの作成と接続ドラッグでノードを近づけるとアンカーに吸着して線が繋がります。8 方向のアンカー、曲線の接続線、矢印の大きさやラベルも設定できます。
  • 多彩なノードの中身メモ、画像・動画・音声・PDF などの添付、Webリンク、表 (テーブル)、チェックリスト、数式、リッチテキストをノードに格納できます。
  • 図形と装飾・フローチャート端子直線・矢印・長方形・楕円・波線・塗りつぶしなどの自由図形と、処理・判断 (ひし形)・データベースなど 10 種類のフローチャート端子を搭載。
  • グループ (付箋) ＆ 格納ノード複数ノードを名前付きグループにまとめたり、選択した複数ノードを 1 つの代表ノードに畳んで必要な時だけ展開できます。
  • サブマップ・自動整列・3D地球儀ビュー別ページへのリンク移動、ツリー整列 / 行列整列 / 等間隔配置、集中モード、プレゼンモード、3D 地球儀ビューに対応。
  • 横断検索・一括編集・マップ統合ノード検索 (マークダウン・文書・フリーノート本文、PDF メモ、ファイル名も対象)、範囲選択での一括編集 / 一括 AI 処理、複数ページの統合に対応。

ページの種類 ＆ 対話型チュートリアル

6つの基本ページ型と AI スタジオを用途に合わせて使い分けられます。

  • マインドマップ自由配置とツリー構造を兼ね備えた無限ノードキャンバス。
  • ギャラリー (本棚)動画・PDF・画像をタイルに並べる 2 次元グリッド。お気に入り・タグ絞り込み、見終わった動画の自動削除や連続再生にも対応。
  • フリーノート手書きペン・蛍光ペン・図形・付箋の自由キャンバス。スタイラスペンや指での筆記、用紙切替、PDF を読み込んでその上に直接書き込む機能に対応。
  • 文書ページ見出し・表・画像・アウトライン目次・文字数カウント付きの文書作成ページ。
  • ファイル / マークダウンマークダウンを書きながらリアルタイムプレビュー。Mermaid 図表・LaTeX 数式・AI による差分比較適用・Web 公開 (Max) に対応。
  • ビデオエディター ＆ AI スタジオタイムライン式の動画編集ページ (トリミング・カット・テロップ・書き出し) と、AI でプレゼン用スライド (.pptx) を自動生成する AI スタジオを搭載。
  • 対話型チュートリアル (実演ガイド)すべてのページ種類にステップ形式の対話型チュートリアルを搭載。実際のキャンバス上で動きが自動実演され、終了後は元の状態にそのまま戻ります。
  • フォルダ・ピン留め・並べ替えページはフォルダ階層で整理でき、ピン留め / お気に入り / 非表示 / ドラッグ並べ替えに対応。

AI (Jev 自動選択 ＆ プリペイド方式)

API キーの用意は不要。Free プランから 3 大 AI をすぐに使えます。

  • API キー不要のプリペイド (Free プランから利用可)AI はアプリ側のキーで動作。アプリ内で $10 単位でチャージし、使った分 (各社の API 実費 + 30%) だけ差し引かれます。応答のたびに消費額と残高が表示されます。
  • Jev (自動 AI 選択) ＆ 3 大 AI 切替おまかせモード「Jev」が質問内容に応じて最適な AI・モデル・思考深度を自動選択。Gemini / ChatGPT / Claude の最新モデルを手動で選ぶことも可能です。
  • マップの自動生成 ＆ ノード深掘りキーワードやテーマからマップを丸ごと生成。選択ノードの解説作成、子ノード展開、30 言語一括翻訳、要約もワンタップで行えます。
  • ファイル / スキャン PDF からの生成長文 PDF (スキャン画像 PDF も対応) や Word / Excel / PowerPoint を読み込んで、マインドマップ (Max) や解説付き問題集を自動生成します。
  • AI クイズ・フラッシュカード・AI 会話練習「まとめて採点 / 即時採点」や「AI 会話学習」に対応したフラッシュカード、4択クイズ、音声での面接・語学ロールプレイができる AI 会話練習を搭載。

動画・PDF・Office 文書

見る / 書き込む / 編集するまでスマホ・タブレットの中で完結します。

  • 広告なし YouTube 埋め込み ＆ 尺フィルターJev による広告非表示プレーヤーで、再生リストやチャンネルの動画を集中視聴。「5分以上20分未満」などの尺フィルター、0.25〜4倍速、横並びメモ＆AI要約に対応。
  • ローカル動画 (最大 16 倍速) ＆ 音楽プレーヤーローカル動画は最大 16 倍速まで高速再生可能。バックグラウンド再生・プレイリスト・クロスフェード対応の音楽プレーヤーも搭載。
  • ネイティブ PDF ビューア ＆ 直接書き込み保存手書きペン・蛍光ペン・図形の PDF 本体への直接焼き込み保存、ページ固有の PDF メモ、目次・サムネイル、見開き表示、ダークモード反転に対応。
  • Office 3形式 (Word / Excel / PowerPoint) 直接編集docx / xlsx (数式エンジン・複数シート対応) / pptx (プレゼンターモード付き) / csv / txt をアプリ内で開いてそのまま編集・保存できます。
  • 画像編集 ＆ 音声読み上げ (TTS)画像のトリミング (矩形 / フリーハンド)・注釈・テキスト入れ、および PDF やテキストの音声読み上げ (TTS) に対応。

Web 検索・リサーチ・試験対策

ニュース・雑学・性能比較・商品検索・317資格試験対策をアプリの中で調べられます。

  • アプリ内 Google 検索 (広告ブロック搭載)検索しながら選択した文章をワンタップで出典 URL 付きノード化。ブックマーク、タブ、履歴、2画面分割に対応。
  • トレンド (9分野 ＋ 動画タブ) ＆ 雑学IT・経済・株・科学など 9 分野の最新ニュース＆動画トレンド (尺フィルター対応) と、科学・歴史・宇宙・生物などの出典明記「雑学」記事・動画をアプリ内で閲覧＆AI要約。
  • 性能比較 (CPU / GPU / スマホ / タブレット / AI性能＆料金 / ブラウザ)CPU (世代・発売年フィルター対応)、GPU、スマホ、タブレット (専用タブ)、ブラウザ、AI (LLM 性能＋OpenRouter 連携の「LLM の料金」トークン単価・円換算比較タブ) を最大 8 件並べて比較できます。
  • 4大EC横断「商品検索」＆ Kindle 書籍検索Amazon・楽天市場・メルカリ・ヤフオクの 4 サイトをアプリ内で横断検索・価格比較。Kindle 表紙検索や新刊カレンダーにも対応。
  • 資格試験の日程 (317試験・過去問118試験) ＆ AI「試験対策」317 の資格試験の日程・受験料・合格率・過去問リンク (118試験) を網羅。さらに「試験対策」では、試験名や学校の科目（高校数学・数3など）から AI が重要用語の収集、分野・難易度別の演習問題生成（LaTeX 数式対応）、過去問サイト/PDF からの暗記カード作成を自動で行います。

予定・データ保護・クラウド同期・共同編集

作ったノートを確実に守り、PC とスマホ間でシームレスに同期します。

  • カレンダー・リマインダー・ガントチャート予定の登録・グループ共有、ルーチン複製、正確なアラーム通知、タスク期間を俯瞰するガントチャートを搭載。
  • フラッシュカード (まとめて採点・会話学習)全ページ横断のデッキ・フォルダ管理、「まとめて採点」と「即時採点」の切替、AI との音声/テキスト「会話学習」、CSV / Excel インポート、PDF・画像・Office 資料からの AI 自動生成に対応。
  • 自動保存・世代バックアップ・復元センター編集ごとの即時自動保存と世代バックアップに加え、消したページや過去の版を一覧してワンタップで戻せる「復元センター」を搭載。
  • クラウド同期 (3-Way 自動マージ・Max) ＆ 共同編集Windows と Android で同時編集しても上書き消失しない 3-Way 自動マージ同期、招待コードでのリアルタイム共同編集、マークダウンの Web 公開リンク発行、同一 Wi-Fi 内の LAN 共有に対応します。

集中ロックと内蔵ユーティリティ

スマホの誘惑を断ち切って学習・作業に集中するための仕組みです。

  • 集中ロックToDo タスクをすべて終えるまで、または指定時間まで画面をロック。スケジュールでの自動ロックにも対応します。
  • ロック画面内の学習環境ロック中もメモ、今日の予定、ポモドーロタイマー、自然音 / ブラウンノイズ BGM、許可した AI や検索の利用が可能です。
  • 内蔵ツール・MCP サーバー・30 言語 UI電卓 / 関数電卓、ストップウォッチ、タイマー、天気、世界時計、アラーム音、MCP サーバー、そして 30 言語の UI 切り替えに対応しています。
