— Privacy Policy

HisatorNotebook（以下「本アプリ」）は、利用者の情報をどのように取り扱うかを 以下のとおり定めます。 本アプリは広告配信・アクセス解析・クラッシュ収集の 仕組みを一切組み込んでいません。 また、取得した情報を第三者に販売することは ありません。
事業者 久田 浩靖 所在地・電話番号は 特定商取引法に基づく表記 に記載しています。
連絡先 hisatasan1@gmail.com アプリ内メニューの「バグ報告・機能依頼」からもご連絡いただけます。
起動しただけで
送信される情報		 本アプリは、起動時に次の情報を自動的に取得・送信します。
  • 端末ごとの匿名 ID（Firebase 匿名ユーザー ID）：氏名やメールアドレスとは結びつきません。
  • IP アドレス（通信の宛先として不可避に送信されるもの）
  • 端末の国・言語設定
  • 最終利用日時
  • ご契約中のプランおよび AI 利用残高の照会
年齢・性別・生年月日は取得しません。 位置情報も、利用者が明示的に地図・天気・位置情報を使う機能を 操作しない限り取得しません。
ご利用に応じて
送信される情報		 次の情報は、利用者がその機能を使ったときにのみ送信されます。
  • Google ログインをした場合：メールアドレス、表示名、プロフィール画像、言語設定
  • クラウド同期・共有・公開を使った場合：ページの本文、メモ、予定、添付した画像・PDF・動画
  • AI 機能を使った場合：入力した文章、ページの内容、PDF から取り出した文字、添付した画像
  • 有料プランを購入した場合：プラン、課金の開始・終了日、クーポンコード、AI 利用量と金額
  • お問い合わせをした場合：本文、表示名、ご契約中のプラン
  • アプリ内ブラウザの位置情報：おおよその位置（市区町村程度）を当方のサーバーが返します。
端末の中だけに
保存される情報		 次のものは当方のサーバーへ送信されません。
  • 画面録画・スクリーンショット
  • 交通系 IC カードの読み取り結果（表示とコピーのみ）
  • アプリ内ブラウザが保存する Cookie（設定から消去できます）
利用目的
  • 端末をまたいだ設定・プラン・AI 残高の同期
  • グループ共有・共同編集・Web 公開機能の提供
  • AI 機能の実行および利用量に応じた課金計算
  • 有料プランの決済・解約・返金の処理
  • お問い合わせへの対応
  • 不正利用の防止（送信回数の制限など）
広告配信および行動ターゲティングには利用しません。
AI 機能について AI 機能を利用すると、入力された文章・ページの内容・PDF から取り出した文字・ 添付画像は、当方が運営する中継サーバー（api.hisator-notebook.com、 Cloudflare, Inc. の基盤上）を経由し、当方名義の API キーを用いて 次のいずれかに送信されます。
  • Google LLC（Gemini API）
  • OpenAI
  • Anthropic PBC
中継サーバーは、送信された内容および応答の本文を保存しません。 利用者ごとの利用量（トークン数と金額）の合計のみを記録します。 各 AI 事業者における取り扱いは、各社の規約に従います。 AI 機能のご利用にあたり、利用者ご自身で AI 事業者の API キーを ご用意いただく必要はありません。
委託先 取り扱いを委託している事業者は次のとおりです。
  • Google LLC：認証、データベース（ページ・予定・添付ファイル）、ファイル保管
  • Cloudflare, Inc.：中継サーバーの実行基盤、契約情報・利用量の保管、公開ページの保管
  • Stripe, Inc.：決済処理（Windows 版・Web 版）
  • RevenueCat, Inc.：サブスクリプション管理（Android 版・iOS 版）
Stripe および RevenueCat には、購入を照合するため匿名 ID を引き渡します。 カード情報は当方には届きません。
端末から直接
接続する先		 次は当方を経由せず、利用者の端末から直接接続します（当方は内容を受け取りません）。
  • Open-Meteo（スイス）／OpenStreetMap 財団：天気機能で選んだ地点
  • Google（YouTube）：保存した動画の題名・サムネイルの取得、検索
  • Wikimedia 財団、DuckDuckGo, Inc.、DeepL SE：調べ物・翻訳機能
  • 端末 OS の音声認識：AI 会話練習の音声会話（Android では多くの場合 Google の仕組みが使われます）
  • 利用者がアプリ内ブラウザで開いたすべてのサイト
外国にある
第三者への提供		 上記の事業者はいずれも日本国外に所在します。
  • アメリカ合衆国：Google LLC、OpenAI、Anthropic PBC、Stripe, Inc.、RevenueCat, Inc.、Cloudflare, Inc.、DuckDuckGo, Inc.
  • ドイツ：DeepL SE
  • スイス：Open-Meteo
各国の個人情報保護制度および各社の保護措置については、各社の公表資料をご参照ください。
保存期間
  • 無料プラン：クラウドに保存したページと添付ファイルは、アップロードから 7 日後に自動的に削除されます。
  • 有料プラン：解約から 30 日後に削除されます。
  • Web 公開したページ：指定した期間（既定 7 日、最長 30 日）の経過後に自動的に失効します。
  • アカウント情報（匿名 ID、表示名、国、言語、プラン、利用量）：削除のお申し出をいただくまで保存します。
  • お問い合わせの内容：対応の記録として保存します。
開示・訂正・削除 保有する情報の開示・訂正・削除・利用停止をご希望の場合は、上記の連絡先までご連絡ください。 ご本人であることを確認のうえ対応します。 現時点で、アプリ内にアカウントを削除する機能はありません。 削除をご希望の場合はご連絡ください。 なお、ご自身のノートの書き出し（JSON / .hnmap / HTML / PDF など）は アプリ内でいつでも行えます。
安全管理 通信は TLS により暗号化しています。 クラウドに保存されたデータへのアクセスは、共有グループに参加している利用者に限られます。 端末に保存される認証情報は、端末内のアプリ領域にのみ保存され、 当方のサーバーには送信されません。 共同編集および Web 公開の機能で作成したページは、そのコードまたは URL を 知っている方であれば閲覧できます。取り扱いにご注意ください。
識別子の利用 広告目的の識別子は使用しません。 機能の提供のため、次の識別子を利用します。
  • 端末ごとに発行される匿名 ID（アプリを削除するまで保持されます）
  • 購入の照合のため Stripe および RevenueCat に引き渡される同 ID
  • アプリ内ブラウザで訪問したサイトが設定する Cookie（設定から消去できます）
お子様の利用 本アプリは年齢の確認を行っておらず、子どもの個人情報を意図して取得することはありません。 本アプリには、フィルタリングを行わないブラウザ機能および他の利用者との共有機能が 含まれます。 保護者の方が、お子様が本アプリを通じて個人情報を提供したことに 気づかれた場合は、上記の連絡先までご連絡ください。 確認のうえ削除します。
本ポリシーの改定 本ポリシーの内容は、法令の変更または機能の追加にあわせて改定することがあります。 重要な変更を行う場合は、アプリ内またはウェブサイト上で告知します。
