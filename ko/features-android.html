Android 버전만의 기능

휴대하며 쓰기 좋고 다른 일을 ‘하면서’ 쓰기에도 편한 모바일 전용 기능 모음입니다

  • 오토 클리커(멀티 스텝·플로우 형식)다른 앱 위에 조작 패널을 띄워 탭·스와이프·이미지 인식·OCR 조건 분기를 순서대로 자동 실행(알기 쉬운 첫 권한 설정 가이드 포함)
  • 무음 카메라(사진·동영상) & OCR·QR 리더도서관이나 교실에서도 셔터음 없이 사진·동영상을 촬영하고, 그 자리에서 OCR 텍스트 추출이나 QR 읽기를 실행
  • 백그라운드 재생 & PiP(작은 창 재생)화면이 꺼진 상태의 백그라운드 재생과, 동영상을 작은 창으로 띄운 채 맵이나 노트를 편집할 수 있는 PiP 지원
  • 상하 / 좌우 화면 분할 & 120Hz/144Hz 렌더링2화면 분할·플로팅 메모와 고주사율 기기에서의 부드러운 렌더링, 집중 잠금 지원

마인드맵 & 6가지 페이지

터치 조작으로도 PC와 똑같은 6가지 페이지 유형과 대화형 튜토리얼을 갖추고 있습니다

  • 마인드맵 & 갤러리이미지·동영상·PDF·표·수식을 담을 수 있는 무한 맵과, 자료를 타일처럼 늘어놓는 2차원 갤러리
  • 프리 노트 & 문서스타일러스나 손가락으로 자유롭게 쓰는 손글씨 캔버스와, 아웃라인 목차가 있는 문서 페이지
  • 마크다운 & 동영상 편집·AI 스튜디오Mermaid·LaTeX·차이 비교를 지원하는 마크다운과, 타임라인 동영상 편집·AI 슬라이드 생성

AI(3대 AI & 선불 방식)

API 키 없이 Free 플랜부터 3대 AI를 바로 쓸 수 있습니다

  • API 키 없이 쓰는 선불 AI$10 충전 후 쓴 만큼만 차감, ChatGPT / Gemini / Claude를 API 키 없이 이용 가능
  • 맵 자동 생성·암기 카드·AI 회화 연습주제나 PDF로 맵·문제집·암기 카드를 생성하고, 음성으로 하는 면접·어학 롤플레이 지원

동영상·PDF·Office·리서치·클라우드 동기화

시청·직접 편집·시험 대비·PC와의 3-Way 동기화까지 스마트폰 하나로 해결

  • 광고 없는 YouTube & PDF·Office 직접 편집광고 숨김 YouTube 시청, PDF에 펜 필기를 그대로 새겨 저장, Word / Excel / PowerPoint 직접 편집
  • 검색·트렌드·잡학·성능 비교·317개 시험 대비2화면 Google 검색, 9개 분야 트렌드, 잡학, CPU/GPU/스마트폰/LLM 비교, 4대 쇼핑몰 상품 검색, AI 시험 대비
  • 자동 저장·복원 센터·3-Way 클라우드 동기화즉시 자동 저장과 복원 센터로 데이터를 보호하고, Windows와 충돌 없이 3-Way 자동 병합 동기화(Max)
