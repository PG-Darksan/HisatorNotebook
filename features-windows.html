Windows 版ならではの機能

デスクトップの広い画面・マウス・キーボードを最大限に活かした機能群です。

  • マウスジェスチャー (全12形状)マップ・フリーノート・ギャラリー・マークダウン・PDF/Office・Google検索の上で右クリックを押しながら上下左右 (4方向) やL字 (8方向) を描くだけで、前後のページ移動、指定ページ/ファイルの即時起動、画面キャプチャ (全画面/ウィンドウ/範囲指定してその場で貼り付け)、またはヘッダーの任意の機能を即実行できます。
  • 画面分割 (2 / 4 分割) ＆ ドラッグ入替マップ・ギャラリー・フリーノート・PDF・マークダウン・Web・AI を同時に並べて表示。上下 / 左右 / 4分割を切り替えられ、各ペイン上部の取っ手をドラッグして左右入れ替え・全画面化・フローティング小窓化・画面端への折り畳みが自在に行えます。
  • ペインへのボタン配置 ＆ フローティング窓ヘッダーのボタンを各ペインへドラッグして配置可能。動画・Web・ツールを浮かぶ小窓にし、「埋め込む」でいつでも分割画面へ戻せます。
  • 操作ボタンのカスタマイズヘッダーと画面の上下左右の端のバーに、好きな機能のボタンを配置可能。ページの上に落とすと丸いフローティングアイコンになり、ヘッダーを隠して画面を広く使えます。
  • キーボードショートカット ＆ Ctrl+1〜9 即起動約 60 のコマンドを自由に割り当て / 個別に無効化。キーボード図で割り当て済みのキーが色分け表示され、Ctrl+1〜9 にはよく使うページやローカルファイルを登録して瞬時に開けます。
  • マウス操作 ＆ 2クリック裁断右クリックメニュー (項目の並べ替え・出し入れ可能)、範囲選択、2 クリック裁断 (接続線の切断)。拡大率は Ctrl + / Ctrl − と ±5% ボタンで微調整できます。
  • オートクリッカー (フロー形式)クリック・連打・スワイプ・矢印キー / ホイール・文字入力・待機・画像認識・OCR条件分岐・リンクを開く・スクショをカードにして並べ、「▶ 順に実行」で自動化。入れ子の繰り返し、位置や間隔の揺らぎ、フローの保存と読み込み、撮影したスクショの一括 PDF 化 (右綴じ縦書き対応) まで完結します。
  • PC の快適化設定 (DDC/CI・キーリマップ)画面ごとの明るさ調整 (外部モニターも DDC/CI 通信で制御)、ブルーライトカット、離席時の自動減光、Bluetooth の入 / 切、Copilot キーや CapsLock などのキー入れ替え (リマップ) をアプリ内から設定できます。
  • マルチモニター・マウスワープ画面の端から反対側へカーソルをループ移動させたり、解像度が異なる複数モニター間の段差 (引っかかり) を補正して滑らかに移動できます。設定の配置図で辺ごとに接続 ON/OFF を指定可能です。

マインドマップ

ノード・接続・グループ・図形。思考を形にする中心機能です。

  • ノードの作成と接続ドラッグでノードを近づけるとアンカーに吸着して線が繋がります。8 方向のアンカー、曲線の接続線、矢印の大きさやラベルも設定できます。
  • 多彩なノードの中身メモ、画像・動画・音声・PDF などの添付、Webリンク、表 (テーブル)、チェックリスト、数式、リッチテキストをノードに格納できます。
  • 図形と装飾・フローチャート端子直線・矢印・長方形・楕円・波線・塗りつぶしなどの自由図形に加え、角丸端子・処理・判断 (ひし形)・入出力・準備 (六角形)・書類・データベースなど 10 種類のフローチャート端子を搭載。
  • グループ (付箋) ＆ 格納ノード複数ノードを名前付きグループにまとめて背景色・整列を指定したり、選択した複数ノードを 1 つの代表ノードに畳んで必要な時だけ展開できます。
  • サブマップ・自動整列・3D地球儀ビュー別ページへのリンク移動、ツリー整列 / 行列整列 / 等間隔配置、集中モード、プレゼンモード、さらにノードを立体球面上に展開する 3D 地球儀ビューに対応。
  • 横断検索・一括編集・マップ統合ノード検索 (マークダウン・文書・フリーノート本文、PDF メモ、ファイル名も対象)、範囲選択での一括編集 / 一括 AI 処理、複数ページの 1 ページ統合に対応。

ページの種類 ＆ 対話型チュートリアル

6つの基本ページ型と AI スタジオを用途に合わせて使い分けられます。

  • マインドマップ自由配置とツリー構造を兼ね備えた無限ノードキャンバス。
  • ギャラリー (本棚)動画・PDF・画像をタイルに並べる 2 次元グリッド。行 / 列を掴んで増減でき、お気に入り・タグ絞り込み、見終わった動画の自動削除や連続再生にも対応。
  • フリーノート手書きペン・蛍光ペン・図形・付箋の自由キャンバス。無地 / 方眼 / 横罫 / ドットの用紙切替や、PDF を読み込んでその上に直接手書きすることも可能です。
  • 文書ページ見出し・表・画像・アウトライン目次・文字数カウント付きの文書作成ページ。PDF 書き出しにも対応。
  • ファイル / マークダウンエディター・プレビュー・見出し・変更差分 (Diff) を最大 4 画面に並べて執筆。Mermaid 図表・LaTeX 数式・AI 差分適用・Web 公開 (Max) に対応。
  • ビデオエディター ＆ AI スタジオタイムライン式の動画編集ページ (トリミング・分割・結合・テロップ・BGM・MP4書き出し) と、資料からプレゼン用スライド (.pptx) を自動生成する AI スタジオを搭載。
  • 対話型チュートリアル (実演ガイド)すべてのページ種類にステップ形式の対話型チュートリアルを搭載。実際のキャンバス上で操作が自動実演され、終了後は元の画面状態にそのまま戻ります。
  • フォルダ・ピン留め・ワークスペースページはフォルダ階層で整理でき、ピン留め / お気に入り / 非表示 / ドラッグ並べ替えに対応。複数のフォルダーを並べて開けます。

AI ＆ 4大 AI CLI 統合

API キーの用意は不要。おまかせ選択「Jev」とプリペイド方式、さらに 4 大 AI CLI に対応。

  • API キー不要のプリペイド (Free プランから利用可)AI はアプリ側のキーで動作。アプリ内で $10 単位でチャージし、使った分 (各社の API 実費 + 30%) だけ差し引かれます。応答のたびに消費額と残高が表示されます。
  • Jev (自動 AI 選択) ＆ 3 大 AI 切替おまかせモード「Jev」が質問内容に応じて最適な AI・モデル・思考深度を自動選択。もちろん Gemini / ChatGPT / Claude の最新モデルを手動で選ぶことも可能です。
  • Claude Code / Codex CLI / Gemini CLI / Antigravity CLIWindows (ストア外配布版) では AI アシスタント内で 4 大 AI CLI を直接起動可能。ご自身の契約で動くため Free プランでも利用でき、5時間枠・週間枠の使用率バー表示 (/usage 連携・リセット日時表示) にも対応しています。
  • MCP サーバー内蔵 (ワンクリック設定・Ctrl+Z 対応)アプリ内に MCP サーバーを内蔵し、「Antigravity 用をコピー」等のボタン 1 つで外部 AI ツールと接続。AI による編集はプレビュー (dryRun) 確認や Ctrl+Z での一括取り消しに対応しています。
  • マップの自動生成 ＆ ノード深掘りキーワードやテーマからマップを丸ごと自動生成。選択ノードの解説作成、関連子ノード展開、30 言語一括翻訳、要約もワンタップで行えます。
  • ファイル / スキャン PDF からの生成長文 PDF (文字情報のないスキャン画像 PDF も対応) や Word / Excel / PowerPoint を読み込んで、マインドマップ (Max) や解説付き問題集を自動生成します。
  • AI クイズ・フラッシュカード・AI 会話練習「まとめて採点 / 即時採点」や「AI 会話学習」に対応したフラッシュカード、4択クイズ、面接・語学ロールプレイができる AI 会話練習 (音声対応・講評付き) を搭載。

動画・PDF・Office 文書・無音カメラ

見る / 書き込む / 編集するまで、外部ソフトなしでアプリの中で完結します。

  • 広告なし YouTube 埋め込み ＆ 尺フィルターJev による広告非表示プレーヤーで、再生リストやチャンネルの動画を丸ごと取り込んで集中視聴。「5分以上20分未満」などの尺フィルター、0.25〜4倍速、横並びメモ＆AI要約に対応。
  • ローカル動画 ＆ 音楽プレーヤーローカル動画を倍速調整や小窓（PiP）で快適に再生でき、速度は次の動画にも引き継がれます。音楽プレーヤー (プレイリスト・クロスフェード・バックグラウンド再生) も搭載。
  • ネイティブ PDF ビューア ＆ 直接書き込み保存手書きペン・蛍光ペン・図形の PDF 本体への直接焼き込み保存、各ページ固有の PDF メモ、目次・サムネイル、見開き 2 ページ表示、ダークモード反転に対応。
  • Office 3形式 (Word / Excel / PowerPoint) 直接編集docx / xlsx (SUM・IF・VLOOKUP 等の数式エンジン・複数シート対応) / pptx (プレゼンターモード・タイマー付き) / csv / txt をアプリ内でそのまま開いて編集・保存できます。
  • 無音カメラ (写真・動画) ＆ OCR・読み上げシャッター音なしで撮影できる無音カメラ (写真モード＆音声録音 ON/OFF 対応の動画モード)、撮影画像の OCR 文字起こし、QR 読取、PDF/テキストの音声読み上げ (TTS) に対応。

Web 検索とブラウザ自動化

調べ物からノート化、定型 Web 操作の自動化まで 1 か所で完結します。

  • アプリ内 Google 検索 (広告ブロック搭載)検索しながら選択テキストをワンタップで出典 URL 付きノード化。ブックマーク、タブ、履歴、2〜4 画面分割、マウスジェスチャー、開発者ツール (F12)、ファイルダウンロードに対応。
  • Web の自動操作 (Pro / Max)タップ / ホールド / スワイプ / スクロール / 待機 / スクショを並べて自動実行。「繰り返し」ブロックで定型チェックや収集作業を何度でも自動再生できます。
  • 自動スクロール撮影 ＆ 右綴じ PDF 化縦長ページや電子書籍を自動スクロールで連続撮影し、重複部分の自動トリミング、見開きの左右分割、右綴じ（縦書き本用）/ 左綴じを指定した一括 PDF 化に対応します。
  • ブラウザ AI ＆ 外部サイト連携ChatGPT / Gemini / Claude / Perplexity 等をアプリ内ブラウザで開いてノード内容を送れるほか、Google マップ / Earth / カレンダー / ドライブ / DeepL / Kindle 等をワンタップで呼び出せます。

情報を集める・比べる・試験対策する

トレンド・雑学・ベンチマーク性能比較・商品検索・317資格試験対策をアプリ内に集約。

  • トレンド (9分野 ＋ 動画タブ)IT・経済・株・仮想通貨・スポーツ・国内・国際・科学・エンタメの最新ニュースと急上昇ワードを一覧表示。YouTube / TVer の動画トレンド（尺フィルター対応）や AI による記事要約・用語解説に対応。
  • 雑学 (記事 / 動画・出典明記)動物・歴史・科学・宇宙・食べ物・ビジネスの厳選メディアから雑学・豆知識の記事や動画を収集。出典 (媒体名) を明記してアプリ内でそのまま閲覧でき、気づきを即ノード化できます。
  • 性能比較 (CPU / GPU / スマホ / タブレット / AI性能＆料金 / ブラウザ)CPU (シリーズ・世代・発売年フィルター対応)、GPU、スマホ、タブレット (専用タブ)、ブラウザ (OS別 Speedometer 3)、AI (LLM 性能ベンチマーク＋OpenRouter 連携の「LLM の料金」トークン単価・円換算比較タブ) を最大 8 件並べて比較し、違いを AI に解説させられます。
  • 4大EC横断「商品検索」＆ Kindle 書籍検索Amazon・楽天市場・メルカリ・ヤフオクの 4 サイトをアプリ内の商品グリッドで横断検索・価格比較。Kindle ストアの表紙一覧検索 (価格帯・Unlimited 絞り込み) や新刊カレンダーにも対応。
  • 資格試験の日程 (317試験・過去問118試験) ＆ AI「試験対策」317 の資格試験の日程・申込期間・受験料・合格率・過去問リンク (118試験) を一覧し、試験日や締切をカレンダーへ登録可能。さらに「試験対策」では、試験名や学校の科目（高校数学・数3など）を入力すると AI が重要用語の収集、分野・難易度別の演習問題生成（LaTeX 数式対応）、過去問サイト/PDF からの暗記カード作成を自動で行います。

予定・データ保護・クラウド同期・共同編集

3段階のデータ保護と、競合しない 3-Way 自動マージ同期・リアルタイム共同編集。

  • カレンダー・リマインダー・ガントチャート予定の登録・グループ共有、ルーチン複製、メンバー予定表、Windows トースト通知リマインダー、タスク期間を俯瞰するガントチャートを搭載。
  • フラッシュカード (まとめて採点・会話学習)全ページ横断のデッキ・フォルダ管理、「まとめて採点」と「即時採点」の切替、AI との音声/テキスト「会話学習」に対応。CSV / Excel の直接インポートや PDF・画像・Office 資料からの AI 自動生成も可能です。
  • 3段階のデータ保護 ＆ 復元センター①1文字ごとの自動保存＋世代バックアップ、②アプリ内ゴミ箱＋Windows の「ごみ箱」への自動退避（ごみ箱の「元に戻す」でアプリへ復帰）、③消したページや過去の版を一覧してワンクリックで戻せる「復元センター」で大切なデータを守ります。
  • クラウド同期 (3-Way 自動マージ・Max)Windows と Android で同時編集しても上書き消失しないノード単位の 3-Way 自動マージ同期（月 25GB アップロード / 100GB ダウンロード）。
  • リアルタイム共同編集 ＆ Web 公開 (Max) ＆ LAN 共有招待コードでファイルや予定表・ページを共同編集（オーナー/編集者/閲覧者権限）でき、マークダウンの Web 公開リンク発行や、同一 Wi-Fi / LAN 内の端末への直接配信にも対応します。

集中ロックと内蔵ユーティリティ

誘惑を断ち切って作業に没頭するためのツール群です。

  • 集中ロック (画面ロック)ToDo タスクをすべて終えるまで、または指定時間まで画面をロック。曜日・時刻スケジュールでの自動ロックにも対応します。
  • ロック画面内の作業環境ロック中もメモ、今日の予定、ポモドーロタイマー、自然音 / ブラウンノイズ BGM、許可した AI や検索の利用が可能です。
  • 内蔵ツール ＆ 30 言語 UI電卓 / 関数電卓、ストップウォッチ、タイマー、天気、世界時計 (タイムゾーン)、アラーム音、そして日本語・英語・中国語・韓国語など 30 言語の UI 切り替えに対応しています。
