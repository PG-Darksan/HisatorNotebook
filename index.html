CHAPTER 08 · 3-LAYER DATA PROTECTION & SYNC

大切な思考を絶対に失わない。
3段階のデータ保護と3-Wayクラウド同期。

どれほど多機能でも、書いたノートが消えてしまっては意味がありません。HisatorNotebook はローカルファーストの高速動作を守りながら、3重のセーフティネットと競合しないクラウド同期でデータを守り抜きます。

🛡️ LAYER 1 · AUTO-SAVE & SNAPSHOTS

1文字ごとの自動保存 ＆ 世代バックアップ

保存ボタンを押す必要はありません。編集のたびに即座に端末へ保存され、万が一の強制終了やバッテリー切れでも直前の状態から再開できます。定期的なスナップショットから過去の時点へ巻き戻すことも可能です。

♻️ LAYER 2 & 3 · RECYCLE BIN & RECOVERY CENTER

Windows「ごみ箱」への自動退避 ＆ 緊急用「復元センター」

削除したページはアプリ内のゴミ箱に残るだけでなく、Windows 版ではOS標準の「ごみ箱」にも自動でバックアップコピーが退避されます。さらにアプリ内の「復元センター」から、自動世代バックアップやゴミ箱のデータを一覧してワンクリックで救出できます。

☁️ 3-WAY MERGE SYNC & CO-EDITING

3-Way 自動マージ同期・共同編集・Web公開（Max）

Windows と Android で同じページを同時に編集しても、ノード単位の 3-Way 自動マージにより上書き消失を防ぎます。招待コードによるリアルタイム共同編集（オーナー／編集者／閲覧者権限）や、マークダウンページの Web 公開リンク発行にも対応しています。

FAQ

よくある質問

導入前によくいただくご質問をまとめました。

Q. AI を使うのに OpenAI や Google、Anthropic の API キーは必要ですか？
いいえ、API キーの用意は一切不要です。 アプリ内で $10 単位のプリペイドクレジットをチャージするだけで、ChatGPT・Gemini・Claude のすべてをすぐに使い始められます（どの AI を使うか自動で選ぶ「Jev」も標準搭載しています）。また、Windows（ストア外配布版）で Claude Code・Codex CLI・Gemini CLI・Antigravity CLI をすでにお使いの方は、その契約をアプリ内の AI アシスタントから直接呼び出すことも可能です。
Q. Free（無料）プランではどこまで使えますか？
マインドマップ・ギャラリー・フリーノート・文書・マークダウン・ビデオエディターの6つのページ作成、PDF への直接書き込み、Word / Excel / PowerPoint の編集、リサーチ・トレンド・雑学・性能比較・317資格試験対策、12形状のマウスジェスチャーまで期間制限なしで無料でお使いいただけます。Free プランでは「同時に開けるページが一覧の先頭2ページまで」となりますが、ページの並び替えやピン留めは自由に行えるため、開きたいページを先頭に移動すれば何枚でも編集できます。
Q. インターネットに繋がっていない環境（オフライン）でも使えますか？
はい、問題なく使えます。 HisatorNotebook はデータをまず端末内に保存する「ローカルファースト」設計のため、マインドマップやノートの作成・編集、PDF の閲覧・書き込み、Office ファイルの編集、ローカル動画の再生などはすべてオフラインで高速に動作します（AI 機能、Web 検索、クラウド同期のみ通信が必要です）。
Q. 誤ってページを削除したり、PC が強制終了したときにデータは消えませんか？
3段階の保護機能で守られています。 ① 編集内容は1文字ごとに自動保存され、定期的な世代バックアップも自動で記録されます。② ページを削除してもアプリ内のゴミ箱に残るほか、Windows 版では Windows 標準の「ごみ箱」にも自動でバックアップファイルが退避されます。③ 万が一の際もアプリ内の「復元センター」から過去のバックアップを選んでワンクリックで復元できます。
Q. Windows と Android の両方でデータを同期して使えますか？
はい、Max プランのクラウド同期でシームレスに連携できます。 両方の端末で同じページを同時に編集した場合でも、ノード単位の「3-Way 自動マージ」によってお互いの変更が自動で統合されるため、片方の作業が上書きされて消える心配がありません。Free / Pro プランでも、ファイル書き出し（エクスポート／インポート）で端末間のデータ移動が可能です。
Q. 初めての操作で迷わないか心配です。
各ページ（マインドマップ・ギャラリー・フリーノート・文書・ファイル/マークダウン・ビデオエディター）の右上のヘルプから、対話型チュートリアルをいつでも起動できます。実際の画面上でノードの追加やペン描画などの動きが自動で実演され、終了後は元の画面状態にきれいに戻るため、安心して試すことができます。
