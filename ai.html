AI 機能 ＆ 4大 CLI 統合

— ChatGPT・Gemini・Claude を「Jev」が自動選択。API キー不要のプリペイドと 4 大 AI CLI 統合

— 01 / Auto Generate & Jev Routing

トピックから、マップが立ち上がる
AI 選びは「Jev」におまかせ

書きたいテーマを入力するだけで、AI が説明文と関連する子ノードを自動で展開します。詳細度は 「分かり易く / 標準 / 詳しい」 から選択可能。
さらに自動選択モード 「Jev」 を選べば、質問の性質（論理推論・長文読解・高速要約・コーディング）に合わせて ChatGPT・Gemini・Claude の中から最適なモデルと思考の深さを自動でルーティングします。

  • Jev (自動 AI 選択): どの AI を使うか迷わず、常に最適な最新モデルで応答
  • 3 段階の詳細度 ＆ 網羅モード: 広いテーマも複数バッチに分割して漏れなくツリー化
  • Web 検索 ＆ 出典 URL 付き回答: 最新ニュースや仕様も Web 検索と組み合わせて正確に回答
  • Free プランから利用可能: API キーの登録なしで、チャージした分だけすぐ使える
— 02 / 4 AI CLIs & Built-in MCP Server

Claude Code・Codex・Gemini・
Antigravity CLI をアプリ内に統合

Windows（ストア外配布版）では、AI アシスタントのパネルから Claude Code・Codex CLI・Gemini CLI・Antigravity CLI を直接起動できます。ご自身のサブスクリプション契約で動作するため、Free プランでも追加のトークン費用なしで利用可能です。

  • 5時間枠・週間枠の使用率表示: /usage 連携により、Gemini や Claude / GPT の残りクォータとリセット日時をリアルタイム表示
  • MCP サーバー内蔵: 「Antigravity 用をコピー」などのワンクリック設定で、外部 AI から現在のページやノードを直接操作
  • プレビュー (dryRun) ＆ Ctrl+Z 巻き戻し: AI が行ったノード追加や文書編集も、差分確認や Ctrl+Z で安全に元へ戻せます

— 04 / File summarization · Max プラン専用

長文 PDF・Office 資料から、
1分でマップが立ち上がる

PDF（テキスト選択できないスキャン画像 PDF も自動認識）・Word・Excel・PowerPoint・テキスト・コード等のファイルを添付すると、AI がファイル全体を読み込んで要約とともにマインドマップを自動生成します。章立て・要点・関連情報をノードとして整理するため、長尺の論文や仕様書もひと目で全体像を掴めます。

  • スキャン画像 PDF にも対応: 文字情報がない PDF でも自動で画像認識に切り替えて解析
  • 網羅モード連携: 長大なファイルもチャンク分割して漏れなくマップ化
  • 元ファイルへの参照を保持: 生成されたマップからいつでも元の資料を参照可能
  • 問題集・カード生成は全プラン対応: PDF からのクイズ・暗記カード生成はプリペイドで全プラン利用可
— 05 / Prepaid credit & Cost Transparency

API キーの用意は不要
使った分だけの明朗プリペイド

AI はアプリ側で用意したキーで動作するため、面倒な開発者アカウント登録や API キー設定は一切不要です。前払いのクレジットから使った分（API 実費 + 30%）だけ差し引かれる仕組みで、使わない月に AI 料金はかかりません。

  • $10 単位でチャージ: Free プラン（¥0）のままでも、必要なときだけチャージして全 AI を利用可能
  • 使った分だけ (実費 + 30%): 各社の公開 API 単価に 30%（決済・中継手数料）を足した額のみ消費
  • LLM の料金比較タブ搭載: 「性能比較」画面で各モデルの 100 万トークン単価（円換算）をいつでも一覧比較
  • 残高と消費額を毎回表示: 応答のたびに消費トークン・概算コスト・残り残高がひと目で分かる
  • 端末をまたいで残高共有: 同じアカウントでログインすれば Windows と Android で残高を共通利用
