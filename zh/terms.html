使用条款

— Terms of Use & Content Guidelines

本条款规定了 HisatorNotebook（以下简称「本应用」）的使用条件。自您使用本应用之时起，即视为您已同意本条款。由于本应用包含与其他用户共享、协同编辑页面的功能以及通过 URL 公开页面的功能，本条款对上述功能的处理作出了专门规定。
禁止事项 禁止以下行为。
  • 违反法律法规的行为，以及共享、公开侵犯他人著作权、商标权、肖像权或其他权利的内容
  • 未经本人同意，上传、公开他人的个人信息或敏感信息，或将其输入 AI 功能
  • 色情、暴力、歧视性内容，骚扰，冒充他人
  • 以不正当手段获取共享代码或协同编辑代码，查看或篡改他人页面的行为
  • 将 Web 公开功能用于骚扰、欺诈或传播违法内容的行为
  • 通过自动化或大批量执行滥用 AI 功能
  • 以违反目标网站使用条件的方式使用 Web 自动操作功能的行为
  • 对本应用进行解析、篡改，以及提取 API 密钥或认证信息
共享与公开
内容的责任
  • 已加入共享群组的用户，可查看上传至该群组的页面、日程表及附件。
  • 通过协同编辑及Web 公开创建的页面，凡知道其代码或 URL 者，任何人均可查看。
对于所共享、公开的内容合法且不侵犯第三方权利，由进行共享、公开的用户承担责任。
举报 如所共享、公开的内容存在问题，请通过应用内菜单中的「错误报告 / 功能建议」或hisatasan1@gmail.com与我们联系。 收到举报后，我方将确认相关内容，并在认为必要时删除该内容、停止公开或限制其使用。此外，从应用内发送的消息限制为每 3 小时最多 10 条。
由我方进行的
删除与停止使用		 对于我方判断违反或可能违反本条款的内容，我方可不经事先通知予以删除、设为非公开或停止其使用。
付费套餐与
解约		 付费套餐的解约方式因购买渠道而异。
  • Windows 版、Web 版（Stripe）：可通过应用内的「订阅管理」解约。
  • Android 版、iOS 版：请通过各应用商店的订阅管理页面解约。
  • Microsoft Store 版：与 Windows 版相同，通过 Stripe 支付。可通过应用内的「订阅管理」解约（不会显示在 Microsoft 账户的订阅管理中）。
费用、支付时间、解约条件及可否退款的详细信息，记载于特定商业交易法相关标示中。
AI 生成内容的处理 本应用不保证 AI 功能输出内容的准确性、完整性及对特定目的的适用性。对生成内容的使用，请由用户自行承担责任。 AI 功能使用 Google LLC、OpenAI、Anthropic PBC 中任一方的服务。所发送内容的处理方式记载于隐私政策中。有关生成内容的权利，亦遵循各 AI 服务商的条款。

使用		 本应用包含浏览和使用以 YouTube 为首的第三方服务的功能。使用这些服务时，请同时遵守各服务的使用条款。对于第三方服务的内容及可用性，我方不承担责任。
关于数据
丢失		 对于因使用本应用而导致的数据丢失或损坏，除因我方故意或重大过失所致的情形外，我方不承担责任。 建议您使用应用内的导出功能（JSON / .hnmap / HTML / PDF 等）定期备份重要数据。此外，通过云同步（Max 套餐）保存在云端的数据，将在解约 30 日后被自动删除（设备内的数据将保持不变）。
