隐私政策

— Privacy Policy

HisatorNotebook（以下简称「本应用」）就如何处理用户信息作出如下规定。本应用未嵌入任何广告投放、访问分析或崩溃收集机制。此外，本应用不会将所收集的信息出售给第三方。
经营者 久田 浩靖 所在地及电话号码记载于特定商业交易法相关标示中。
联系方式 hisatasan1@gmail.com 您也可以通过应用内菜单中的「错误报告 / 功能建议」与我们联系。
仅启动即
发送的信息		 本应用在启动时会自动收集并发送以下信息。
  • 每台设备的匿名 ID（Firebase 匿名用户 ID）：不与姓名或电子邮箱地址相关联。
  • IP 地址（作为通信目的地址而不可避免地发送的信息）
  • 设备的国家/地区及语言设置
  • 最后使用时间
  • 当前订阅的套餐及 AI 使用余额的查询
本应用不收集年龄、性别及出生日期。除非用户明确操作使用地图、天气或位置信息的功能，本应用亦不会收集位置信息。
根据使用情况
发送的信息		 以下信息仅在用户使用相应功能时发送。
  • 使用 Google 登录时：电子邮箱地址、显示名称、头像、语言设置
  • 使用云同步、共享或公开功能时：页面正文、笔记、日程、附加的图片、PDF 及视频
  • 使用 AI 功能时：输入的文本、页面内容、从 PDF 中提取的文字、附加的图片
  • 购买付费套餐时：套餐、计费开始及结束日期、优惠券代码、AI 使用量及金额
  • 提交咨询时：正文、显示名称、当前订阅的套餐
  • 应用内浏览器的位置信息：由我方服务器返回大致位置（约为市、区、町、村一级）。
仅在设备内
保存的信息		 以下内容不会发送至我方服务器。
  • 屏幕录像、屏幕截图
  • 交通 IC 卡的读取结果（仅用于显示和复制）
  • 应用内浏览器保存的 Cookie（可在设置中清除）
使用目的
  • 跨设备同步设置、套餐及 AI 余额
  • 提供群组共享、协同编辑及 Web 公开功能
  • 执行 AI 功能及按使用量计算费用
  • 处理付费套餐的支付、解约及退款
  • 回复咨询
  • 防止不当使用（如限制发送次数等）
不用于广告投放及行为定向。
关于 AI 功能 使用 AI 功能时，输入的文本、页面内容、从 PDF 中提取的文字及附加图片，将经由我方运营的中转服务器（api.hisator-notebook.com，基于 Cloudflare, Inc. 的平台），使用以我方名义持有的 API 密钥，发送至以下任一服务商。
  • Google LLC（Gemini API）
  • OpenAI
  • Anthropic PBC
对于所发送的内容及响应，中转服务器不保存其正文。仅记录每位用户使用量（Token 数及金额）的合计。各 AI 服务商对数据的处理遵循其各自的条款。使用 AI 功能时，用户无需自行准备 AI 服务商的 API 密钥。
委托方 我方委托处理信息的服务商如下。
  • Google LLC：身份验证、数据库（页面、日程、附件）、文件存储
  • Cloudflare, Inc.：中转服务器的运行平台、订阅信息及使用量的存储、公开页面的存储
  • Stripe, Inc.：支付处理（Windows 版、Web 版）
  • RevenueCat, Inc.：订阅管理（Android 版、iOS 版）
为核对购买记录，我方会向 Stripe 及 RevenueCat 提供匿名 ID。银行卡信息不会传送至我方。
由设备直接
连接的对象		 以下对象不经由我方，由用户设备直接连接（我方不接收其内容）。
  • Open-Meteo（瑞士）／OpenStreetMap 基金会：在天气功能中选择的地点
  • Google（YouTube）：获取已保存视频的标题与缩略图、搜索
  • Wikimedia 基金会、DuckDuckGo, Inc.、DeepL SE：查询及翻译功能
  • 设备操作系统的语音识别：AI 对话练习中的语音对话（在 Android 上多数情况下使用 Google 的机制）
  • 用户在应用内浏览器中打开的所有网站
向位于境外的
第三方提供		 上述服务商均位于日本境外。
  • 美利坚合众国：Google LLC、OpenAI、Anthropic PBC、Stripe, Inc.、RevenueCat, Inc.、Cloudflare, Inc.、DuckDuckGo, Inc.
  • 德国：DeepL SE
  • 瑞士：Open-Meteo
关于各国的个人信息保护制度及各公司的保护措施，请参阅各公司公开的资料。
保存期限
  • 云同步（Max 套餐）：自解约之日起 30 日后，云端的页面及附件将被自动删除（Free 及 Pro 套餐的数据仅保存在设备内）。
  • 已 Web 公开的页面：在指定期限（默认 7 日，最长 30 日）届满后自动失效。
  • 账户信息（匿名 ID、显示名称、国家/地区、语言、套餐、使用量）：保存至您提出删除申请为止。
  • 咨询内容：作为处理记录予以保存。
披露、更正、删除 如您希望我方披露、更正、删除或停止使用所持有的信息，请通过上述联系方式与我们联系。我方将在确认您本人身份后予以处理。 目前，应用内尚无删除账户的功能。如需删除，请与我们联系。此外，您可随时在应用内导出自己的笔记（JSON / .hnmap / HTML / PDF 等）。
安全管理 通信采用 TLS 加密。对云端所存数据的访问仅限于已加入共享群组的用户。保存在设备上的认证信息仅存储于设备内的应用区域，不会发送至我方服务器。 通过协同编辑及 Web 公开功能创建的页面，凡知道其代码或 URL 者均可查看。请谨慎处理。
标识符的使用 本应用不使用以广告为目的的标识符。为提供功能，本应用使用以下标识符。
  • 按设备发放的匿名 ID（保留至删除本应用为止）
  • 为核对购买记录而提供给 Stripe 及 RevenueCat 的同一 ID
  • 在应用内浏览器中访问的网站所设置的Cookie（可在设置中清除）
儿童的使用 本应用不进行年龄确认，亦不会有意收集儿童的个人信息。本应用包含不进行内容过滤的浏览器功能以及与其他用户的共享功能。如监护人发现儿童通过本应用提供了个人信息，请通过上述联系方式与我们联系。我方确认后将予以删除。
本政策的修订 本政策的内容可能会因法律法规的变更或功能的增加而修订。如有重大变更，我方将在应用内或网站上予以公告。
